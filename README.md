# FAQ-бот для репетиции Hackalem.ai

Терминальный бот отвечает на пять заранее известных вопросов о репетиции: время, команда, трек, сдача и призы. Точные ответы хранятся в [`faq.txt`](faq.txt), поэтому их можно менять без правки кода.

Сначала бот ищет совпадение по словам и русским основам слов. Если локально вопрос не распознан и задан `AI_API_KEY`, OpenAI-совместимая модель выбирает наиболее близкий пункт FAQ. Модель не генерирует ответ, поэтому бот не выдумывает факты. Если совпадения нет или AI API недоступен, бот отвечает «Не знаю».

## Запуск через Docker Compose

Требования: Docker с плагином Compose.

```bash
cp .env.example .env
# При необходимости укажите AI_API_KEY в .env
docker compose run --rm faq-bot
```

AI-ключ необязателен: основной сценарий работает локально. Для OpenAI оставьте значения `AI_BASE_URL` и `AI_MODEL` из примера. Для другого OpenAI-совместимого ресурса измените их в `.env`.

Пример диалога:

```text
Вы: куда отправлять решение?
Бот: Загрузите решение в репозиторий команды и добавьте README с инструкцией по запуску.

Вы: какая погода?
Бот: Не знаю. Попробуйте спросить про время, команду, трек, сдачу или призы.
```

Завершение: `выход`, `exit` или `Ctrl+C`.

## Запуск без Docker

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
FAQ_PATH=faq.txt python app.py
```
